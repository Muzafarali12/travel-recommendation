# TravelBloom - Travel Recommendation Web Application

A simple travel website where users can search for beaches, temples and countries and see recommendations with images.

## Live Website
https://YOUR-USERNAME.github.io/travel-recommendation/

## Features
- **Home page** with an introduction and a search bar
- **About Us page** with the mission and team
- **Contact Us page** with a name, email and message form
- **Navigation bar** with Home, About Us and Contact Us links
- **Search and Clear buttons** on the navigation bar
- **Recommendations** loaded from a JSON file, each with an image and description

## How to Search
| Keyword | Result |
|---|---|
| `beach` | Beach recommendations |
| `temple` | Temple recommendations |
| `country` | City recommendations from all countries |
| `Japan`, `Australia`, `Brazil` | Cities from that country |

## Run Locally
Open the folder in VS Code and start it with the **Live Server** extension. Opening `index.html` directly will not load the JSON data.
